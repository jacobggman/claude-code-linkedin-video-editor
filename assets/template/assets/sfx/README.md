# Sound effects

`scripts/setup.py` fills this folder on first run with the 19 sound effects the template uses (whooshes, pops,
clicks, chime, sparkle, impacts, glitches, typing, riser...). They come from Pixabay under the Pixabay Content
License, which allows using them inside your videos but not redistributing the files on their own, so they are
downloaded from the HyperFrames project instead of being stored in this repo.

To swap in your own, drop an `.mp3` here with the same name.
